Tool 接口解剖 src/tools/types.ts

interface Tool

  • name — 工具名（硬编码字符串，防打包器改名）
  • description — 面向模型的描述（多在 prompts.ts）
  • category — "read" | "write" | "command"
  • deferred? — 延迟加载，仅 MCP 工具为 true，需经 ToolSearch 拉出 schema
  • isConcurrencySafe?(args) — 按实参判断可否并发；未实现时按 category 回退（read 可并发）
  • schema() — 返回 ToolSchema（含 input_schema JSON Schema）
  • execute(ctx, args) — 执行并返回 ToolResult
  • dispose?() — 释放资源（如 Bash 的沙箱、LSP 会话）

ToolResult 输出

  • output: string — 文本结果（必选）
  • isError: boolean — 是否为错误
  • contentBlocks? — 富内容块：text / image / document / tool_reference / search_result
  • mcpApp? — MCP App（内联 HTML 应用）

ToolContext 要点

cwd、abortSignal、taskManager（后台任务）、fileStateCache（读后写门禁）、fileHistory、permissionChecker、onPermissionRequest、onOutput、goalManager、sessionId 等。

沙箱模型

OS 级沙箱仅包裹 Bash：macOS 用 Seatbelt（/usr/bin/sandbox-exec），Linux 用 bubblewrap（bwrap）。配置 SandboxConfig {allowWrite, denyWrite, networkEnabled}。

/sandbox auto|manual|off 运行时切换；auto 模式下权限层对非危险 Bash 命令自动放行（Layer 3.5）。PowerShell 明确不套沙箱（两种沙箱都包 bash，且 Windows 无 OS 沙箱）。

所有工具另受权限系统 PathSandbox 路径边界与 permission rules 约束。

MCP 加载模式

eager（全进 tools[]）/ native（defer_loading + tool_reference）/ dispatch（不进 tools[]，经 McpCall 转发）。
