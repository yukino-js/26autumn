## 优先级建议

| 顺序 | 主线                                   | 理由                                                                 |
| ---- | -------------------------------------- | -------------------------------------------------------------------- |
| 1    | RAG / Agent 全链路（1–33）             | 出现密度最高，且常以整套连问出现                                     |
| 2    | 指标口径与项目真实性（127–131）        | 最容易被追问穿：答不出「怎么统计的」比答不出数字更致命               |
| 3    | MCP / 工具生态（34–50）                | 可用项目源码事实校正通行表述，区分度高                               |
| 4    | Go / 网关 / 存储一致性（51–60、74–96） | 固定题型，机制与取舍有标准答案                                       |
